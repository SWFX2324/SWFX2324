I'm Ethan, and I build **Swamp Fox Labs**: free, open tools for radio operators. They plan links before you go out, keep you connected in the field, and bring radio data home.

## Projects

| Project | What it is |
| --- | --- |
| [**RF Toolkit**](https://github.com/SWFX2324/swamp-fox-labs-rf-toolkit) | Radio planning in the browser: link budgets, mesh planning and coverage maps over real terrain (Longley-Rice), plus antenna, coax and satellite calculators. Works offline. **[Open the app →](https://swfx2324.github.io/swamp-fox-labs-rf-toolkit/)** |
| [**TAK Plugins**](https://github.com/SWFX2324/swamp-fox-labs-tak-plugins) | Plugins for WinTAK, starting with OpenMANET mesh monitoring. **[Latest release →](https://github.com/SWFX2324/swamp-fox-labs-tak-plugins/releases/latest)** |
| [**Home Assistant Apps**](https://github.com/SWFX2324/swamp-fox-labs-ha-apps) | A Ham Radio Dashboard for Home Assistant: HF propagation, space weather, DX spots, repeaters, APRS, POTA and satellite passes, with sensors and alerts. |

## Built with

TypeScript · C# / WPF · Node.js · Leaflet · Home Assistant
